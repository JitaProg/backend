## Cómo ejecutar el proyecto
Instrucciones iniciales para ejecutar el proyecto localmente:

1. Clonar el repositorio.
2. Instalar las dependencias en las carpetas correspondiente (`frontend` y `backend`).
3. Iniciar los servicios según corresponda.
